# Pinned exactly, and the reason is the hash commitments rather than tidiness.
# The sealed prediction path runs scipy.signal.savgol_filter, numpy gradient and
# convolve, and scipy.spatial.cKDTree. If any of those changes an edge case or a
# tie-break in a minor release, the published SHA-256 values stop reproducing,
# and nobody could tell a library update apart from an author quietly editing a
# call. Reproducing a sealed prediction means reproducing this environment, so
# the environment is part of what was committed to.
#
# These are the versions the 2026 season locks were produced under, on
# CPython 3.14.3 / Windows. Newer versions may well give identical bits; that is
# a claim to test, not to assume.

numpy==2.4.4
scipy==1.17.1
matplotlib==3.10.8
